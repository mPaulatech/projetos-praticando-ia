## Sobre o desenvolvimento

Landing page desenvolvida com HTML e CSS puro, a partir de uma imagem de 
referência (design). Pedi para a IA gerar a estrutura inicial com base na 
imagem, e revisei o código para garantir que entendia cada parte — seletores, 
layout (flexbox/grid) e responsividade.

**O que pratiquei:**
- Leitura e organização de código HTML semântico
- Estruturação de layout com CSS a partir de um design pronto
- Ajustes de responsividade
