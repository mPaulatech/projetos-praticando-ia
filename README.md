# Estudos Fullstack com IA

Repositório com projetos feitos durante meus estudos de desenvolvimento fullstack, 
usando ferramentas de IA (GitHub Copilot e Codex) como apoio no processo.

## Sobre este repositório

Sou estudante de Gestão da Tecnologia da Informação e tenho domínio sólido de 
HTML e CSS. Os projetos aqui envolvem tecnologias que ainda estou aprendendo 
(React, Node.js, banco de dados etc.), e usei IA como ferramenta de apoio — 
não como substituta do aprendizado.

Cada projeto tem uma seção "Sobre o desenvolvimento" explicando o que eu fiz 
sozinha, onde usei IA e o que aprendi com isso.

## Por que uso IA nos estudos

Uso IA do mesmo jeito que uso documentação ou tutorial: pra entender como 
resolver um problema, tirar dúvida específica ou acelerar tarefas repetitivas. 
O objetivo é aprender a tecnologia, não só entregar um projeto pronto.
