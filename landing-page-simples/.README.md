# Landing Page Simples

Landing page desenvolvida com HTML e CSS puro, a partir de uma imagem de 
referência (design).

## Sobre o desenvolvimento

Pedi para a IA (GitHub Copilot) gerar a estrutura inicial do HTML e CSS 
com base na imagem de referência. Revisei o código gerado para entender cada 
parte: estrutura semântica do HTML, seletores CSS e organização do layout.

**O que pratiquei:**
- Leitura e organização de código HTML semântico
- Estruturação de layout com CSS a partir de um design pronto
- Ajustes de espaçamento e alinhamento

## Tecnologias

- HTML5
- CSS3

## Como visualizar

Basta abrir o arquivo `index.html` no navegador.
